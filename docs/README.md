# Documentación

## Libro de referencia

Este proyecto sigue la estructura de:

> Batchelder, W. S. (2024). *Data Governance Handbook: A practical approach to building trust in data* (1.ª ed.). Packt Publishing. ISBN 978-1-80324-072-5.

El libro tiene copyright, así que **no se incluye ni se reproduce en este repositorio**. Los microproyectos solo lo citan: usan los títulos de los capítulos y resumen las ideas con palabras propias.

Si tienes una copia legítima, puedes guardarla en esta carpeta para consultarla en local. `.gitignore` excluye los archivos `*.pdf`, `*.epub` y `*.mobi` de `docs/`, así que nunca se subirán.
